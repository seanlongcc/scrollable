# AI Artifacts Archive

This directory keeps historical AI-generated planning material and design mockups that may still be useful for product archaeology, visual reference, or future refactors.

These files are reference-only. They are not production source of truth, and future implementation should prefer current source code, migrations, `README.md`, `AGENTS.md`, and the curated files under `docs/agent/`.

## Contents

- `mockups/` - Historical static HTML and image mockups for workbench and library UI directions.
- `superpowers/specs/` - Historical design specs created during feature planning.
- `superpowers/plans/` - Historical implementation plans created during feature work.
- `superpowers/prompts/` - Raw AI prompt artifacts from refactor planning.

## Cleanup Policy

If an archived artifact contains a durable product decision, summarize that decision in a current documentation file instead of linking production work directly to the artifact. Delete archived files only when they are clearly duplicated, misleading, or no longer useful as context.
